Hi, it's me Skie 109, I made a game in Python called Apple Picking Simulator

What is this game about:
The game involves picking apples from the tree,
and then selling them for coins, which are used to buy baskets, as the first basket holds a maximum of four apples.
Your goal is to buy the largest basket to win the game.
The game was created in Poland

What I want to add in v.1.1:
English Language Choice
changing biomes and new baskets

Have a nice game :P
