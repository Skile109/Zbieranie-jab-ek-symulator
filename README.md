Hi, it's me Skile 109, I made a game in Python called Zbieranie jabłek symulator (Apple Picking Simulator)

What is this game about:
The game involves picking apples from the tree,
and then selling them for coins, which are used to buy baskets, as the first basket holds a maximum of four apples.
Your goal is to buy the largest basket to win the game.
The game was created in Poland

What I want to add in v.1.1:
English language option, changing biomes
and fix small screen on mobile devices


Have a nice game :P

Cześć, to ja, Skile 109, stworzyłem grę w Pajtonie o nazwie Symulator zbierania jabłek.

O czym jest ta gra:
Gra polega na zbieraniu jabłek z drzewa,
a następnie sprzedawaniu ich za monety, za które kupuje się koszyki, ponieważ pierwszy koszyk mieści maksymalnie cztery jabłka.
Twoim celem jest kupienie największego koszyka, aby wygrać grę.
Gra powstała w Polsce.
